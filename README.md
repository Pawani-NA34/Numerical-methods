# Numerical Methods

This repository contains codes, implementations, and computational exercises related to Numerical Methods, studied as part of the Semester 3 elective course.

The repository documents the numerical techniques and computational approaches explored during the course, using Python.

## Topics Covered
-  Solution of linear systems by Gaussian elimination method
-  LU decomposition
-  Gauss-Seidel method
-  Eigenvalue Problem: Power method, inverse power method.
-  Interpolation: Lagrange and Newton’s methods
-  Newton Cotes quadrature methods.
-  Solution of initial value problems by Euler, modified Euler and Runge Kutta (RK) methods.
-  Finite difference and shooting method
