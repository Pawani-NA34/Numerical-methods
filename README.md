# Numerical Methods

This repository contains codes, implementations, and computational exercises related to Numerical Methods, studied as part of the Semester 3 elective course.

The repository documents the numerical techniques and computational approaches explored during the course, using Python.

## Topics Covered
- item Solution of linear systems by Gaussian elimination method
- item LU decomposition
- item Gauss-Seidel method
- item Eigenvalue Problem: Power method, inverse power method.
- item Interpolation: Lagrange and Newton’s methods
- item Newton Cotes quadrature methods.
- item Solution of initial value problems by Euler, modified Euler and Runge Kutta (RK) methods.
- item Finite difference and shooting method
